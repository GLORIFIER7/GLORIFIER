# Support

## Before asking for help

Please:
1. Read the README.
2. Search existing issues and discussions.
3. Check the relevant documentation under `docs/`.
4. Confirm whether the problem is reproducible and note the environment.

## What to include

For technical problems, provide:
- What you expected.
- What happened instead.
- Reproduction steps.
- Relevant non-sensitive logs or error messages.
- Browser/runtime/OS information when relevant.
- The commit or deployment identifier when known.

**Never post secrets, API keys, access tokens, private keys, passwords, or financial credentials.**

## Security problems

Do not use public support channels for vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## Verification language

When reporting system status, distinguish between:
- configured
- reachable
- authenticated
- successfully executed
- verified by external evidence

This keeps GLORIFIER's operational record truthful.
