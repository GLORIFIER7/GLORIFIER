# Code of Conduct

## Our standard

GLORIFIER is a technical project built around trustworthy AI orchestration, governed execution, interoperability, and evidence-backed outcomes.

Participants are expected to:
- Be respectful, constructive, and professional.
- Discuss ideas and implementation details without personal attacks.
- Welcome good-faith questions, corrections, and differing technical opinions.
- Protect other people's privacy and confidential information.
- Avoid harassment, discrimination, threats, doxxing, spam, and deliberately disruptive behavior.
- Report security vulnerabilities privately rather than publishing exploitable details.

## Project-specific expectations

Because GLORIFIER handles AI providers, agents, credentials, evidence, and governed execution:
- Do not commit secrets, API keys, tokens, private keys, credentials, or personal data.
- Do not claim a system, provider, asset, payment, or outcome is verified without evidence.
- Do not bypass authorization, access controls, quotas, or safety controls.
- Do not introduce automatic irreversible production changes or automatic financial transfers.
- Keep failures truthful: unavailable components must remain unavailable/degraded rather than being represented as successful.

## Enforcement

Maintainers may remove or edit contributions, close discussions, restrict participation, or take other reasonable action when conduct violates this code or threatens project security or integrity.

For urgent safety or security concerns, use the private reporting process described in [SECURITY.md](SECURITY.md).
