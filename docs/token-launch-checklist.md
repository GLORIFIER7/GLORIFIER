# GLORIFIER Token Launch Checklist

## Code
- [ ] Solidity compiler version pinned
- [ ] OpenZeppelin dependency pinned
- [ ] Unit tests pass
- [ ] Static/security analysis completed
- [ ] Deployment wallet isolated
- [ ] Initial holder address confirmed
- [ ] No secrets committed

## Testnet
- [ ] Testnet deployment transaction confirmed
- [ ] Contract address recorded
- [ ] Explorer source verification confirmed
- [ ] Transfer test completed
- [ ] Supply and decimals independently checked

## Mainnet
- [ ] Legal/compliance review completed for the target jurisdiction(s)
- [ ] Deployment wallet funded
- [ ] Initial holder / treasury addresses confirmed
- [ ] Multisig configured for treasury where applicable
- [ ] Mainnet deployment transaction confirmed
- [ ] Explorer verification confirmed
- [ ] Public token documentation updated

## Evidence
Do not mark a deployment as published or verified until the on-chain transaction and contract address are independently observable.
